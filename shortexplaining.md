# Discord API — Short Explanation

The Discord API lets applications communicate with Discord programmatically.

## How it works

1. Create an application in the Discord Developer Portal.
2. Create/configure a bot if your application needs one.
3. Authenticate requests using the appropriate Discord credentials or OAuth2 flow.
4. Send HTTP requests to Discord API endpoints to read or modify resources.
5. For real-time events, use the Discord Gateway.
6. For interactions such as slash commands and buttons, use Discord's interaction system.

The API is organized around resources such as users, guilds (servers), channels, messages, webhooks, and applications.
